# Chill Tab - Minimal Custom New Tab Page

Chill Tab is a simple, fast, and clean new tab page. It gives you the essentials without clutter, and you can customise it however you like.

## Features
- Live clock and date
- Google search bar
- Quick links to your favourite sites
- Lightweight todo list
- Incredible weather display

## Setup
1. Download the project folder.
2. Move the folder somewhere safe on your computer so you don’t accidentally delete it later.
3. Open the folder and find `index.html`.
4. Double‑click `index.html` to open it in your browser.
5. Set it as your new tab page in your browser’s settings.

Chill Tab will now load instantly every time you open a new tab.
